# ProshnoBook — Project Handoff ও কাজের নির্দেশনা

তুমি ProshnoBook-এর coding, deployment, troubleshooting এবং backup/recovery সহকারী।

এই document-কে পূর্ববর্তী session-এর handoff হিসেবে পড়বে। এখানে তিন ধরনের তথ্য আছে:
১. আগের agent-এর যাচাই করা ফলাফল
২. ব্যবহারকারীর জানানো ফলাফল
৩. এখনো যাচাই বাকি বিষয়

এগুলো এক করে দেখবে না। বর্তমান repository, code, hosting settings ও পরীক্ষার ফলাফলই চূড়ান্ত সত্য। আগের tool access এখনো আছে ধরে নেবে না।

কাজ শুরুতে পুরো context পড়বে, বর্তমান repository/branch যাচাই করবে এবং অসমাপ্ত কাজের তালিকা তৈরি করবে। ব্যবহারকারীর পরবর্তী নির্দেশ ছাড়া production পরিবর্তন করবে না।

- tests/blob-backup.test.cjs

Features:
- Manual workflow_dispatch।
- One public Blob store per token।
- Secrets:
  BLOB_READ_WRITE_TOKEN
  BLOB_BACKUP_PASSPHRASE
- Pagination, restricted public Blob URL download,
  size/SHA256 verification, re-list।
- Credential forwarding ও unsafe redirects এড়ানোর ব্যবস্থা।
- Maximum backup size 5 GiB ছিল; code যাচাই করবে।
- TAR manifest।
- scrypt + AES-256-GCM encryption।
- Encrypted archive decrypt/digest roundtrip check।
- Artifact-এ শুধু encrypted archive ও report।
- Retention 7 days।
- No production file delete/modify।
- Snapshot atomic নয়; concurrent changes-এর সব case বাদ যায় না।
- DB/env/vault keys অন্তর্ভুক্ত নয়।

Archive format:
PBLOB001 + salt16 + IV12 + ciphertext + GCM tag16
Authenticated header।
Backup passphrase minimum 20 bytes।

Offline restore/decrypt command:
node scripts/blob-backup-restore.cjs INPUT.tar.enc INPUT.tar.enc.json NEW-OUTPUT.tar

Passphrase privately environment-এ supply করতে হয়।
কখনো chat/command history-তে literal secret লিখতে বলবে না।

এই script:
- encrypted file/report যাচাই করে
- নতুন private TAR তৈরি করে
- existing output overwrite করে না
- production Blob বা database-এ restore করে না

Raw decrypted TAR private রাখবে।
